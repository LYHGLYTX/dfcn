DFCN · Byayoi 同人社区《矮人要塞》简体中文汉化。

Windows x64 精简运行包，适配 **Dwarf Fortress 53.16**，支持 Steam 版与官网免费版。

本次更新让 Windows 汉化配置、词表、TOML 规则、字体和日志按实际 DLL 所在目录定位，支持将完整运行文件保留在 Steam 创意工坊订阅目录。构建和打包工具同时支持源码工作区与游戏目录分开存放。

### GitHub Release 安装

下载附件 **DFCN-Windows-x64-minimal.zip**，解压后将 `dfhooks.dll`、`dfhooks_dfcn.ini` 和整个 `dfcn` 文件夹拷贝到包含 `Dwarf Fortress.exe` 的游戏根目录。例如：

```text
D:/SteamLibrary/steamapps/common/Dwarf Fortress/
  Dwarf Fortress.exe
  dfhooks.dll
  dfhooks_dfcn.ini
  dfcn/
    dfcn_core.dll
    dfhooks_dfcn.dll
    data/runtime/config.ini
```

运行包内的 `dfhooks_dfcn.ini` 已配置为 `dfcn/dfhooks_dfcn.dll`，整包安装无需改动该路径。压缩包包含加载入口、汉化核心、运行配置、词表、TOML 规则及许可说明，不包含源码、开发工具、日志或游戏程序。

### Steam 创意工坊安装

[订阅 DFCN](https://steamcommunity.com/sharedfiles/filedetails/?id=3811193379)后，运行文件直接位于订阅目录的 `DFCN` 文件夹中，无需解压。只将其中的 `dfhooks.dll` 和 `dfhooks_dfcn.ini` 复制到游戏根目录；其余文件保留在工坊目录。

游戏与订阅内容在同一 Steam 库时，游戏根目录中的 `dfhooks_dfcn.ini` 第一行使用：

```text
../../workshop/content/975370/3811193379/DFCN/dfcn/dfhooks_dfcn.dll
```

也可填写实际绝对路径，例如：

```text
D:/SteamLibrary/steamapps/workshop/content/975370/3811193379/DFCN/dfcn/dfhooks_dfcn.dll
```

第一行只写 DLL 路径，不加引号、不写 `key=value`，保存为 UTF-8 无 BOM。加载器自动读取同目录的 `dfcn_core.dll`，汉化设置的 `config.ini` 留在工坊目录的 `DFCN/dfcn/data/runtime/` 下。详细步骤和其他路径示例见工坊描述。

### 开关、升级与卸载

在游戏中按 **Shift+F10** 开启或关闭汉化。

从旧版整包安装迁移到工坊方式时，移除游戏根目录中旧的 `dfhooks_dfcn.dll`（若存在），避免加载两份汉化；旧的 `dfcn` 文件夹可在保留需要的个人配置或资料后移除。

卸载需要手动删除已复制到游戏目录中的汉化文件。Release 整包安装删除本包添加的 `dfhooks.dll`、`dfhooks_dfcn.ini` 和 `dfcn` 文件夹；工坊安装删除复制的两个入口文件，再取消订阅。取消订阅不会自动清理手动复制的文件。

本项目不会破坏或改写磁盘上的游戏本体文件，不修改 RAW 或存档，也无需 DFHack 等外部 Mod。

正常 Windows 编译部署已完成；未操作游戏或观察游戏内最终显示效果。
