DFCN v53.16-20261003.2 · 2026-10-03

Windows x64 精简运行包，适配 Dwarf Fortress 53.16，支持 Steam 版与官网免费版。

本次完善访客求职说明和申请界面汉化，新增全界面中文字体加粗开关，运行包配置默认启用；同时修复知识详情、人格、健康和想法正文在字号放大后被原英文行边界裁切的问题。

更新范围：上次 Release v53.16-20261003（e053198）之后，截至 fe02c18 的全部 5 条开发提交，按提交顺序逐条列出。发布整理同步 GitHub 与工坊版本、安装说明、下载链接及逐条日志。

使用变化

- 新增 font_bold 字体加粗开关，主字体与缺字回退字体共用设置。本次运行包的 config.ini 设置为 font_bold=true；设为 false 可保留原有字重。沿用旧配置且未添加此项时，默认仍为 false。
- 开启 hot_reload 时，修改 font_bold 会随配置自动重载，重新加载字体，并更新字形、测量及排版缓存。
- 申请界面的固定按钮统一译为“批准”“拒绝”，未处理申请提示统一使用“申请”。人物、地点、机构名称及行会职业继续沿用既有名称和职业翻译规则。

逐条更新日志

1. 8294523 (https://github.com/pokemonchw/dfcn/commit/82945231ecc40a4a4dac35d2dae8353b67600539) — 补齐访客概述中求职原因的完整段落翻译，覆盖寻找长期工作、以要塞为佣兵基地、长期从事学术研究三类说明，以及“他／她／它”代词分支。职业和地点按完整字段翻译，两句说明保持为同一段落处理。

2. 06a0dbf (https://github.com/pokemonchw/dfcn/commit/06a0dbf20407468be7916b0e463d941ecbf58836) — 新增 font_bold 开关，统一控制全界面汉化文字、主字体和缺字回退字体的加粗。运行包配置默认启用；设为 false 保留原有字重，旧配置省略此项时仍默认关闭。字体测量和实际绘制共用加粗结果，配置自动重载时同步更新字体及相关缓存。

3. 73856cd (https://github.com/pokemonchw/dfcn/commit/73856cddbf354b943b668b696f7c0d6a61ae6306) — 修正主界面全大写 PETITIONS 提示漏译的问题，与劳动规则中的 Petitions 标签统一译为“申请”。

4. 3f884d9 (https://github.com/pokemonchw/dfcn/commit/3f884d91656af957ac96cffc3ad7d27a1c045b14) — 修复知识详情、人格、健康和想法等共用文档排版的正文在字号放大后，被原英文单行裁剪边界截断的问题。重排后的中文使用完整文档可见区域绘制，保留文本框横向边界，并统一行基线。

5. fe02c18 (https://github.com/pokemonchw/dfcn/commit/fe02c18018ee02287e0ed8cea11db96fe54ae086) — 补齐 Windows 53.16 原生申请界面的各类分支，覆盖神殿／神殿建筑群与祭司任命、行会大厅／大行会大厅、和谈、公民资格及居留申请。居留目的包含庇护、学术研究、军事服务、表演和消灭怪物；同步翻译今后同类申请的“询问／接受／拒绝”设置及劳动规则入口说明。修正“批准”“拒绝”按钮被当作姓名音译的问题，补充列表截短标题的固定前缀，并统一“没有待处理申请”的提示用语。

下载与安装

下载附件 DFCN-Windows-x64-minimal.zip，将 dfhooks.dll、dfhooks_dfcn.ini 和整个 dfcn 文件夹按压缩包目录结构解压到包含 Dwarf Fortress.exe 的游戏根目录。Release 包内入口路径为 dfcn/dfhooks_dfcn.dll。

Steam 创意工坊订阅 (https://steamcommunity.com/sharedfiles/filedetails/?id=3811193379)提供解压后的相同运行内容，完整安装方式见工坊说明；逐条详细日志随订阅内容提供在 CHANGELOG.txt。运行包包含加载器、汉化核心、配置、词表、规则及第三方许可，不包含游戏程序、源码或开发工具。

本次基于现有 Windows DLL 和运行数据打包，未操作游戏或实际观察游戏内最终显示效果。
